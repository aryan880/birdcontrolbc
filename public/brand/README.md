# Bird Control BC Brand Kit

## Final logos

Use files in `final/` for production. SVG files are preferred for websites, print, signs, and vehicle artwork. PNG files are provided for social platforms and tools that do not accept SVG.

- `logo-horizontal`: primary website and general-use logo
- `logo-stacked`: square or vertical placement
- `social-avatar`: profile image with safe circular-crop spacing
- `icon`: browser favicon and small app/profile mark
- `favicon-32.png`: browser-tab export
- `apple-touch-icon.png`: 180px Apple touch icon
- `icon-192.png`: installable app/manifest icon
- `logo-monochrome`: single-colour production artwork
- `logo-dark-background`: reversed logo for forest-green backgrounds
- `logo-vehicle-uniform`: high-contrast contractor identification lockup

## Marketing applications

Files in `applications/` are editable starting points using real Bird Control BC project photography.

- `website-banner`: 1920 x 640
- `social-cover`: 1640 x 624
- `service-poster`: 1080 x 1350
- `tri-fold-pamphlet`: 1800 x 1200

The approved Coastline Wing silhouette is shared across the system. Full lockups include the subtle ledge cue; social and favicon artwork use the bird alone for cleaner recognition at small sizes.
